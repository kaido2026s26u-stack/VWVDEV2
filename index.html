ここから、少しずつ形にする。
GitHub と Codex を使って、作りながら学ぶための小さなプロジェクトです。

01 / EDIT

まず、変えてみる

文章や色を編集して、ファイルの変更がページにどう反映されるか確かめます。

02 / COMMIT

変更を記録する

何を変えたのかを確認し、コミットという区切りで作業の履歴を残します。

03 / PUSH

GitHub に反映する

記録した変更を GitHub に送り、プロジェクトを少しずつ育てていきます。
