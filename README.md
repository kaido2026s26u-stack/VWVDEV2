# VWVDEV2

GitHub と Codex の使い方を、実際にファイルを編集しながら学ぶためのプロジェクトです。

## 入っているもの

- `index.html`：ブラウザで開ける、このプロジェクトの紹介ページ
- `README.md`：GitHub 上に表示されるプロジェクトの説明（このファイル）

## ページを見る

ダウンロードした `index.html` をブラウザで開くだけで表示できます。追加のソフトやライブラリは必要ありません。

Python がある場合は、このフォルダで次のコマンドを実行しても確認できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

同じPCのブラウザで `http://127.0.0.1:8000` を開きます。終了するにはターミナルで `Ctrl+C` を押します。

## 練習すること

1. ページの文章や色を編集する。
2. 差分（変更した箇所）を確認する。
3. コミットで変更を記録する。
4. プッシュで GitHub に反映する。

## GitHub の項目

| 項目 | 役割 |
| --- | --- |
| Code | ファイルと変更履歴を見る |
| Issues | 不具合や、今後やりたいことを記録する |
| Pull requests | 変更案を確認して取り込む |
| Releases | APK などの配布物をバージョンごとにまとめる |

このプロジェクトには、まだ APK やリリースはありません。HTML を追加するだけでは Web サイトとして公開されません。Web サイトの公開には GitHub Pages などの別途設定が必要です。
